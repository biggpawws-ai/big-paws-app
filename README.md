## ¿Qué es Big Paws?

**Big Paws** es una aplicación móvil y extensión web que transforma las compras cotidianas de las personas en una fuente de financiamiento automática, transparente e incorruptible para animales en peligro de extinción.

No le pedimos a la gente que done dinero.
Le hacemos ganar el dinero que *ya van a gastar*
y hacemos que las marcas paguen por la conservación.

```
  🛒  compras café          →   🤖  IA escanea tu ticket
  ⭐  ganas Eco-Puntos      →   🐆  tu jaguar crece en la app
  💸  dinero real llega     →   🌿  ONG protege su hábitat
```

<br/>

---

## 🌍 El Problema

> Cada día, el mundo gasta **$55 mil millones** en compras cotidianas.
> Cada día, **150 especies** se acercan a la extinción.
> Estos dos mundos nunca habían estado conectados.

La conservación tradicional depende de donaciones voluntarias — un modelo roto que alcanza menos del 1% del problema. Big Paws no pide donaciones. **Redirige el flujo de dinero que ya existe.**

## 🧠 Cómo Entra la Inteligencia Artificial

Big Paws tiene tres motores de IA trabajando en tiempo real:

<br/>

**`01` — AI Receipt & Cart Scanner** &nbsp;·&nbsp; *Computer Vision + NLP*

El usuario sube su ticket o conecta su cuenta. La IA identifica cada producto, calcula su huella de carbono e impacto hídrico, y asigna un Eco-Score instantáneo.

<br/>

**`02` — Biodiversity Matchmaker** &nbsp;·&nbsp; *IA Semántica*

Cada compra se vincula con el hábitat de un animal real en extinción:

| Tu compra | Animal | Ecosistema protegido |
|:---|:---:|:---|
| ☕ Café certificado de sombra | 🐆 | Hábitat del Jaguar — Amazonas |
| 🐟 Pescado con sello MSC | 🐬 | Ríos del Delfín Rosado — Orinoco |
| 🌿 Frutas de producción local | 🦅 | Bosque del Águila Arpía |
| 🧴 Cosmético sin aceite de palma | 🦧 | Selva del Orangután — Borneo |
| 🥛 Lácteos sostenibles | 🦁 | Sabana del León Africano |

<br/>

**`03` — Recomendador de Alternativas Verdes** &nbsp;·&nbsp; *Aprendizaje por Refuerzo*

Escaneas un producto de alto impacto → Big Paws responde:

```
⚠️  Alto impacto detectado

💡  Cambia este producto por [Marca Local]
    → Ganarás 2× Eco-Puntos
    → Protegerás 0.3 m² de hábitat del jaguar
```

## 💰 Modelo de Negocio

> Los usuarios son **gratis**. Las marcas pagan todo. El planeta gana.

Big Paws opera con tres fuentes de ingresos autónomas y escalables:

<br/>

**🤝 Comisiones por Afiliación**
Las marcas sostenibles pagan entre el **5% y 15%** por cada compra generada desde Big Paws. ROI rastreable y demostrable.

<br/>

**🏢 SaaS Enterprise — El Sello Big Paws**
Las corporaciones necesitan resultados ESG reales. Les vendemos software para patrocinar especies enteras. Resultado para la marca:

> *"Gracias a nuestra alianza con Big Paws, nuestros clientes protegieron 847 km² de hábitat jaguar este trimestre."*

Eso no es marketing. Es un **activo ESG auditable**.

<br/>

**📊 Anuncios Hiper-segmentados por IA**
Big Paws tiene la audiencia con mayor intención de compra sostenible del mundo. Las marcas pagan para aparecer exactamente cuando el usuario está buscando consumir mejor.

```
  Fuente                Quién paga          Escalabilidad
  ──────────────────────────────────────────────────────
  Afiliación            Marcas medianas     Alta · automática
  Sello Big Paws        Corporaciones       Premium · recurrente
  Anuncios por IA       Cualquier marca     Masiva · global
  ──────────────────────────────────────────────────────
  Usuarios              Gratis              Siempre
```
